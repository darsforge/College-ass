# Gym Management - MERN Mini Project

MongoDB + Express + React (Vite) + Node.

## Run (needs MongoDB running locally on port 27017)

Terminal 1 - backend:
    cd server
    npm install
    npm start          # http://localhost:5000

Terminal 2 - frontend:
    cd client
    npm install
    npm run dev        # http://localhost:5173  (open this one)

Data is saved in database `gymdb`, collection `members`.
View it in MongoDB Compass / VS Code extension with: mongodb://127.0.0.1:27017
